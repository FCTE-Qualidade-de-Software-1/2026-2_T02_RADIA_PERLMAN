# Visão Geral do Projeto

Este site reúne a documentação do projeto prático da disciplina de Qualidade de Software , do curso de Engenharia de Software da Universidade de Brasília (UnB), ministrada pelos professores Cristiane Soares Ramos. 

O objeto de estudo deste projeto é a **Agência Virtual da Neoenergia Brasília**, um software comercial submetido a um rigoroso processo de avaliação de qualidade.

## Fundamentação Teórica

A Engenharia de Software é definida como a aplicação de uma abordagem sistemática, disciplinada e quantificável para o desenvolvimento, operação e manutenção de software . Dentro dessa disciplina, a qualidade de software é um conceito complexo e altamente dependente do contexto, podendo ser percebida de diferentes maneiras.

Segundo Garvin (1984), a qualidade pode ser analisada através de cinco visões principais: transcendental, do usuário, da manufatura, do produto e baseada em valor. Este projeto norteia-se primordialmente pelas seguintes perspectivas:

* **Visão do Usuário:** Avalia o grau em que o produto atende às necessidades e expectativas dos usuários, abrangendo elementos como a usabilidade.
* **Visão do Produto:** Explora as relações causais entre propriedades internas e externas, assumindo que a qualidade pode ser avaliada de maneira objetiva por meio de atributos mensuráveis.

Para padronizar a avaliação, o projeto adota a família de normas **SQuaRE (Software product Quality Requirements and Evaluation)**. Utiliza-se o modelo de qualidade de produto **ISO/IEC 25010**, que categoriza as propriedades do software em características e subcaracterísticas mensuráveis, como eficiência de desempenho, usabilidade, confiabilidade e segurança.


##  O Processo de Avaliação

Para que a qualidade do produto seja mensurada de forma sistemática e repetível, o projeto segue um Processo de Avaliação de Produto de Software estruturado em quatro fases fundamentais:

1. **Fase 1 - Estabelecer requisitos de avaliação:** Etapa de definição do propósito da avaliação, identificação do tipo de produto (escopo) e especificação do modelo de qualidade aplicável (ISO/IEC 25010).
2. **Fase 2 - Especificar a avaliação:** Fase destinada a selecionar as métricas, estabelecer os níveis de pontuação e definir os critérios para o julgamento da qualidade.
3. **Fase 3 - Projetar a avaliação:** Etapa de consolidação do plano de avaliação, detalhando os recursos, os métodos e o cronograma para execução.
4. **Fase 4 - Executar a avaliação:** Fase prática onde são obtidas as medidas, comparados os resultados com os critérios estabelecidos e julgada a qualidade final do software, culminando no relatório de avaliação.
